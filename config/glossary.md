# 專有名詞表

語音辨識常把專有名詞聽錯。這份表有兩個用途：

1. 下面 `prompt` 區塊會餵給 Whisper 當提示，讓它一開始就偏向正確寫法（用繁體＋全形標點，也讓輸出偏向繁體）。**長度別超過約 200 字**，太長反而會被忽略或亂抄。
2. Claude 校對字幕時，照「常見誤聽」那欄修正。

新詞直接加在表格裡；常出現的詞也可以加進 prompt。

```prompt
以下是舒服美隱形牙套的衛教影片，繁體中文。內容包含：隱形牙套、牙齒矯正、咬合、暴牙、戽斗、深咬、開咬、牙縫、齒列擁擠、附件、IPR、維持器、貼片、陶瓷貼片、美白、植牙、牙周病、口內掃描、3D模擬。
```

## 字幕寫法慣例

- 數字用阿拉伯數字：「3 個月」「第 2 副」。
- 不用句號；逗號在畫面上改成空格（渲染時自動處理，資料裡保留標點即可）。
- 口頭禪（「那」「然後」「就是」「對」）若不影響意思可以刪，但不改講者原意。
